X-viewer

Pull the focal tweet + first batch of replies from an x.com page into clean markdown, ready to paste into Claude / Gemini / ChatGPT. All processing runs on your device using your own logged-in X session — no cookies leave the browser, no paid X API.

iPhone install (recommended) iOS Shortcut

The bookmarklet path below is blocked by x.com's CSP on iOS Safari. Build a Shortcut instead — it lives in your share sheet for one-tap access.

How this version works: the iPhone Shortcut reads the already-rendered DOM (focal tweet + replies that have scrolled into view) instead of calling X's API. iOS Shortcuts can't make authenticated requests (the WebView lacks the HttpOnly auth_token cookie), so we side-step authentication entirely. Trade-off: only replies you've already scrolled past are captured.

  1. Open the Shortcuts app on iPhone → tap + (top right) to create a new shortcut.
  2. Tap Add Action → search "Run JavaScript on Web Page" → tap to add it.
  3. In that action, replace the placeholder JavaScript with the snippet below (long-press → Select All → Copy → paste into the action).
  4. Add another action: search "Copy to Clipboard". By default it picks up the previous action's output (the markdown).
  5. Add another action: search "Open URLs" → set the URL to https://claude.ai/new.
  6. Tap the small i info icon at the bottom → enable "Show in Share Sheet" → set "Share Sheet Types" to Safari web pages only.
  7. Rename the shortcut to SendToClaude → Done.

%SHORTCUT_JS%

Using the Shortcut

  1. Make sure you're logged into x.com in Safari.
  2. Open a tweet on x.com in Safari (URL contains /status/<id>).
  3. Tap the share button → scroll the share sheet → tap SendToClaude.
  4. First time: iOS asks "Allow this Shortcut to run JavaScript on x.com?" → Allow Always (saves the prompt every time).
  5. The markdown lands on your clipboard and Claude.ai opens. Long-press in the Claude prompt box → Paste.

Troubleshooting

  • Shortcut returns "ERROR: TweetDetail status=400" — X rotated their schema. Maintainer needs to refresh src/meta.json and rebuild.
  • "ERROR: not logged into X in Safari" — log into x.com in Safari, then try again.
  • "ERROR: not on an X tweet page" — open a single tweet (URL has /status/), not the home timeline.
  • iOS Safari "cannot run JavaScript this way" on bookmarklet — that's x.com's CSP blocking it. Use the Shortcut path instead.
