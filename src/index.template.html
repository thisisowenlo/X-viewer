X-viewer

Pull the focal tweet + first batch of replies on an x.com page into clean markdown, ready to paste into Claude / Gemini / ChatGPT. All processing runs on your device using your own logged-in X session.

Send to Claude

Drag the button to your bookmarks bar (desktop) or follow the steps below (iPhone).

iPhone install (Safari)

  1. Tap the share button on this page, then "Add Bookmark". Save it (any title is fine for now).
  2. Open Bookmarks → Edit → tap your new bookmark.
  3. Replace the Address with the JavaScript shown below (long-press the box, Select All, Copy, then paste into the Address field).
  4. Rename the bookmark to something memorable like SendToClaude.
  5. Done. To use: open a tweet on x.com, tap the address bar, type send, tap the bookmark suggestion.

Desktop install

Drag the blue button above into your bookmarks bar.

Usage

  1. Make sure you're logged into x.com in this browser.
  2. Open a tweet detail page (URL contains /status/<id>).
  3. Trigger the bookmarklet. An overlay appears with the markdown.
  4. Tap "Copy & Open Claude" to copy and jump to claude.ai.

Troubleshooting

  • "TweetDetail failed: status=400" — X rotated their query schema. The site maintainer needs to refresh /api/x-graphql-meta.json.
  • "Login required" — log into x.com in this browser, then try again.
  • "Not on an X tweet page" — open a single tweet (URL contains /status/), not the home timeline.
  • Clipboard didn't work on iPhone — long-press the textarea in the overlay, choose Select All → Copy, then tap Open Claude.
