X-viewer

Pull the focal tweet + replies from an x.com page into clean markdown, ready to paste into Claude / Gemini / ChatGPT. All processing runs on your device — no cookies leave the browser, no paid X API.

iPhone install iOS Shortcut · two paths

iOS Shortcuts has a quirk: "Run JavaScript on Web Page" only accepts a Safari Web Page input, not a URL. So we install two parallel Shortcuts, each with the same name SendToClaude:

  • Shortcut A: triggered from Safari share sheet → reads the rendered DOM directly. Best fidelity (focal tweet + replies that have scrolled into view).
  • Shortcut B: triggered from the X app (or any URL share) → calls a Cloudflare Worker that fetches X's public syndication API. Smaller reply set, but doesn't break.

iOS shows whichever shortcut applies based on the share-sheet input type, so you only ever see one SendToClaude option in any given context.

Step 1 · Deploy the Cloudflare Worker (one-time, ~5 min)

  1. Go to dash.cloudflare.com → sign up (free) → Workers & Pages → Create.
  2. Pick Hello World template → name it e.g. x-viewer-syndication → Deploy.
  3. After deploy: click Edit Code. Replace the entire file with the worker code below, then Save and Deploy.
  4. Copy the deployment URL shown at the top — looks like https://x-viewer-syndication.YOUR-NAME.workers.dev. You'll paste this into Shortcut B.
  5. Quick test: open https://YOUR-WORKER-URL/?url=https://x.com/jack/status/20 in any browser. Should return markdown of Jack's first tweet.

Step 2 · Build Shortcut A (Safari path)

  1. Shortcuts app → + new shortcut.
  2. Add action: "Run JavaScript on Web Page". Replace the placeholder JS with the snippet at the bottom of this page.
  3. Add action: "Copy to Clipboard" (auto-takes previous output).
  4. Add action: "Open URLs" → URL = https://claude.ai/new.
  5. Settings (the ⓘ icon): toggle "Show in Share Sheet". Set Share Sheet Types to Safari web pages only — uncheck everything else, especially URLs.
  6. Name: SendToClaude.

Step 3 · Build Shortcut B (URL / X app path)

  1. Shortcuts app → + new shortcut.
  2. Add action: "Get URLs from Input" (Shortcut Input → URLs).
  3. Add action: "URL". In the URL field, paste: https://YOUR-WORKER-URL/?url= then tap the field, choose Magic Variable, pick the URL from step 2.
  4. Add action: "Get Contents of URL". Method GET. Input: the URL from step 3.
  5. Add action: "Copy to Clipboard".
  6. Add action: "Open URLs" → URL = https://claude.ai/new.
  7. Settings (ⓘ): Show in Share Sheet. Share Sheet Types: URLs only.
  8. Name: SendToClaude (same as A — iOS distinguishes by input type).

Using it

  • From Safari on a tweet detail page → share → SendToClaude → markdown to clipboard, Claude opens.
  • From the X app → share → SendToClaude → Worker returns syndication markdown → clipboard, Claude opens.
  • First run of each: iOS asks for permission. Allow Always.

Troubleshooting

  • "轉換錯誤 / cannot convert URL to Safari Web Page" — Shortcut A was triggered from a non-Safari source. Either restrict A's Share Sheet Types to Safari web pages only (so it stops appearing in X-app share sheet), or make sure Shortcut B is also installed (so X-app shares route there instead).
  • Worker returns "syndication status=403/404" — tweet is deleted, private, age-restricted, or X-only.
  • iOS Safari "cannot run JavaScript this way" on bookmarklet — that's x.com's CSP. Use the Shortcut path on iPhone.
